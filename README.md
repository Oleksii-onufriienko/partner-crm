# Partner CRM — версия 0.1 (скелет)

Облачная CRM для партнёрской структуры: дерево партнёров с кабинетами, Marktpotenzial
каждого партнёра, 6-недельный планер встреч и статистика по структуре.

## Что уже работает

**Роли и структура**
- **Администратор** создаётся при первом запуске и заводит главных бетроеров (верхний уровень).
- Любой человек с кабинетом добавляет людей под себя. Дерево любой глубины.
- Каждый видит себя и всех ниже по структуре. Соседние ветки и людей выше не видно.
- Кабинет открывает тот, кто выше: кнопка «Открыть кабинет» создаёт ссылку-приглашение
  (действует 14 дней, срабатывает один раз). Человек сам задаёт e-mail и пароль.
  Эта же кнопка служит и для сброса забытого пароля.
- Ступень, коэффициент €/KE и наставника меняет только тот, кто выше (или администратор).
- «Деактивировать» закрывает вход, данные остаются в статистике.

**Выбор партнёра вверху.** Если у вас есть команда, над каждой страницей стоит панель
«Мои данные / Смотрю данные партнёра» со списком людей. Выбранный партнёр запоминается:
переходы по меню слева показывают его Marktpotenzial, планер, план/факт и статистику, пока вы
не выберете другого человека или не нажмёте «Вернуться к себе».

**Данные партнёра:** имя, фамилия, ступень (VM, VBA, AL, RGS, GS, HGS, RD, D), коэффициент €/KE
(подставляется по AK1: VM 1, VBA 6, AL 9, RGS 10 — можно изменить), дата рождения, телефон,
e-mail, дата входа в бизнес, цель KE в месяц, заметка.

**Marktpotenzial (контакты):** имя, фамилия, телефон, e-mail, возраст, профессия, канал
(тёплый круг / рекомендация / другое), от кого рекомендация, уровень Kontaktpyramide из AK1
(очень горячий… холодный), тип (потенциальный клиент / клиент), статус (не контактирован,
термин назначен, в работе, перезвонить позже, нет шансов), интерес к партнёрству,
следующий шаг с датой напоминания, комментарий.
- Потенциальные сделки — сколько угодно (продукт + KE), кнопка «Оформить» переносит в сделку.
- Оформленные сделки — дата, продукт, KE. Первая сделка автоматически делает человека клиентом.
- Быстрое добавление строкой прямо в списке — чтобы за вечер выписать 50 человек.
- Сортировка кликом по заголовку любого столбца (повторный клик — в обратном порядке) и фильтры:
  температура, статус, тип, канал, напоминание, потенциал, сделки, возраст, интерес к партнёрству, поиск.
- Температура показана цветом как на термометре: синий (холодный), голубой, жёлтый (тёплый), оранжевый, красный (очень горячий).

**Планер на 6 недель:** сетка по дням, встречи по формату (лично, онлайн, звонок, личное
время) и этапу (холодный контакт, контактный разговор, Fürsprechergespräch, первый термин,
анализ, бератунг, заключение сделки, сервис, семинар, карьерный разговор, обучение).
Бетроер планирует встречи своим партнёрам. Итоги по неделям справа.

**Статистика** за неделю / месяц / прошлый месяц / 6 недель вперёд / квартал / год /
свой период: Marktpotenzial, клиентский потенциал, встречи план и факт, результат план и
факт в KE и €. Лично и по всей структуре, таблица по каждому прямому партнёру с его веткой.
€ считаются по коэффициенту каждого человека.

**График активности** в статистике: линия на каждую активность (новые контакты, первый термин,
анализ, бератунг, заключение сделки, оформленные сделки) по дням (до 3 месяцев), по неделям (до года)
или по месяцам. Каждую линию можно скрыть или показать, есть «Показать все / Скрыть все»,
подсказка при наведении и таблица.

**Слабые места** (автоматически): нет проведённых встреч 14 дней, пустой план на 14 дней,
Marktpotenzial меньше 20 человек, просроченные напоминания, не отмечен итог прошедших встреч,
не указан коэффициент.

**План/факт по неделям** (как Wochenplanung в Erfolgsjournal): 22 строки в блоках FA, бератунг,
сервис и Anwerbung. На каждую неделю — план (Soll) и факт (Ist), итог месяца и процент выполнения.
Факт по встречам и сделкам считается сам (метка «авто»): первые термины, финанализы, бератунги,
сервис-термины, новые клиенты, KE. Рекомендации, карьерные разговоры и интерес к профессии
вносятся вручную. Автофакт можно поправить. Есть «для всех недель» и перенос плана из прошлого
месяца, квоты месяца (как Quoten-Auswertung), итоги по всей структуре и по каждому партнёру,
виджет «Эта неделя» на экране «Сегодня». У сделки появился источник: бератунг или сервис-термин.

**Экран «Сегодня»:** встречи на сегодня с кнопкой «Проведена», кому позвонить, ближайшие
7 дней, своя Kontaktpyramide, дни рождения в команде, команда за месяц.

Светлая и тёмная тема (по системе или переключателем), работает на телефоне.

## Попробовать на своём компьютере (Windows)

1. Установите Python 3.11+ с python.org (галочка «Add Python to PATH»).
2. В папке проекта:
   ```
   pip install -r requirements.txt
   python seed_demo.py demo.sqlite3
   set CRM_DB=demo.sqlite3
   python run.py
   ```
3. Откройте http://localhost:8000 — вход `admin@demo.local` / `demo12345`.
   Другие демо-входы: `irina@demo.local`, `oleg@demo.local` (тот же пароль) — так видно,
   как система выглядит для партнёра.

Без строки `set CRM_DB=...` запускается чистая рабочая база — при первом входе
система попросит создать кабинет администратора.

## Выложить в облако

Самый простой путь — небольшой VPS с дата-центром в Германии (например, Hetzner)
и свой домен:

```
git clone … partner-crm && cd partner-crm     # или скопировать папку
# в Caddyfile вписать свой домен вместо crm.example.de
docker compose up -d
```

Caddy сам получит HTTPS-сертификат. Данные лежат в папке `data/` — её и нужно бэкапить
(одна папка, файл базы SQLite + секретный ключ).

Без Docker: `pip install -r requirements.txt gunicorn`, затем
`CRM_INSTANCE=/путь/к/data CRM_SECURE_COOKIES=1 CRM_BEHIND_PROXY=1 gunicorn -w 2 -b 127.0.0.1:8000 wsgi:app`
и любой reverse proxy с HTTPS.

## Тестовая версия на PythonAnywhere (бесплатно, серверы во Франкфурте)

Один раз:
1. Зарегистрироваться на https://eu.pythonanywhere.com (тариф Beginner).
2. Вкладка Consoles → Bash:
   ```
   git clone https://github.com/<логин-github>/partner-crm.git ~/partner-crm
   mkdir -p ~/crm-data
   ```
3. Вкладка Web → Add a new web app → Manual configuration → Python 3.12 (или новее).
4. Там же открыть «WSGI configuration file», заменить содержимое текстом из `pythonanywhere_wsgi.py`.
5. Включить «Force HTTPS», нажать Reload. Открыть сайт и создать кабинет администратора.

Обновление после изменений в коде (Bash-консоль на PythonAnywhere):
```
cd ~/partner-crm && git pull
```
затем Reload на вкладке Web. База в `~/crm-data` при этом не трогается.

На бесплатном тарифе сайт нужно продлевать раз в месяц кнопкой на вкладке Web.

## Тестовая структура для демонстрации

```
python seed_test_structure.py add    ~/crm-data/crm.sqlite3   # 3 VBA, 1 AL (+1 VBA), 10 VM с контактами и встречами
python seed_test_structure.py remove ~/crm-data/crm.sqlite3   # убрать всех тестовых людей
python seed_test_structure.py plan   ~/crm-data/crm.sqlite3   # заново заполнить им план/факт
```
Тестовые люди помечены «[ТЕСТ]» в заметке, телефоны вымышленные, кабинетов у них нет.

## Важно про данные клиентов

В системе хранятся персональные данные клиентов (DSGVO). Поэтому: только HTTPS, сервер в ЕС,
регулярный бэкап папки `data/`, доступ к серверу — только у вас. Пароли хранятся в виде хэшей,
формы защищены от подделки запросов (CSRF), вход защищён от перебора паролей.

## Структура проекта

```
crm/
  __init__.py     создание приложения, фильтры, заголовки безопасности
  db.py           схема базы (SQLite)
  auth.py         вход, первичная настройка, приглашения, профиль, CSRF
  access.py       кто кого видит (дерево структуры)
  main.py         страницы: сегодня, команда, Marktpotenzial, планер, статистика
  stats.py        расчёт показателей и «слабых мест»
  constants.py    справочники: ступени, этапы встреч, продукты, пороги сигналов
  templates/      страницы
  static/         стили и немного JavaScript
run.py            запуск на своём компьютере
wsgi.py           запуск на сервере (gunicorn)
seed_demo.py      демо-данные
```

Справочники (ступени, этапы, продукты, пороги «слабых мест») меняются в `crm/constants.py`.
